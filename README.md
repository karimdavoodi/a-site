# Al-Salaam Islamic Centre

Website for Al-Salaam Islamic Centre in Kitchener. Plain HTML, CSS, and JavaScript — no build step.

Prayer times come from the [Aladhan API](https://aladhan.com/prayer-times-api) with a live countdown to the next prayer, plus events, a photo gallery, and Zeffy donations.

Hosted at [alsalaam.netlify.app](https://alsalaam.netlify.app/).
